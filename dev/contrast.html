Token contrast audit

Every colour token discovered in the loaded stylesheets, paired and scored against WCAG 2.1. No dependencies – open this file directly from disk.

Serve this folder, do not open the file directly. Chrome treats file:// stylesheets as opaque and blocks cssRules, so token discovery finds nothing and the audit comes back empty. Any static server works. For a headless check that needs no server, run node dev/contrast-check.js.

Increased-contrast mode is not scriptable. To audit it, turn the OS setting on (Windows: Settings → Accessibility → Contrast themes; macOS: System Settings → Accessibility → Display → Increase contrast) and reload. The banner below reports whether prefers-contrast: more is currently active.
